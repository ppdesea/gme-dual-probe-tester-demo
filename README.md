# 双面同时扎针测试机 · 3D 现场演示

GME（广州美维）30×24 双 MOSFET 嵌埋芯片条带的双面同时扎针自动测试机交互演示，测试源 Advantest EVA100。

单文件 `index.html`，用浏览器直接打开即可（Three.js 从 jsDelivr CDN 加载，需要外网）。

## 形态对标

整机形态与自动化对标 Nidec Advance Technology **STAR REC M6ⅡUW**（L/UL 一体、4 工位旋转分度转台、Step & Repeat、封闭机壳）。区别：M6 做 HDI/PCB 线路 Open/Short 电测；本机测嵌埋 MOSFET 的器件参数（VF / IGSS / VS1S2，mV 级 Kelvin），测试源为 Advantest EVA100。页面「对标」页有逐项对照表。

## 演示内容

- **整机 3D 模型**：封闭米色机壳（可透视）、料盒舱与上下料取放机构、2D 读码器、4 工位分度转台与格栅真空载具 + 张力夹、对位相机、C 型框架 + XY 步进台、上针头 + 上压板、下针头、INA 前端板、后部 EVA100 机柜（512ch 两台）、主操作屏、灯带与急停、三色灯、双开防护门、AGV 对接（选配）。悬停显示部件功能，7 个视角预设，剖视·分层展开。
- **节拍**：四工位并行（投入 3 s / 对位 2 s / 测试 N × 1.2 s / 排出 3 s）+ 转位 1.5 s，周期由测试工位决定；512 / 256 / 128 ch 分别每次扎 2 列 / 1 列 / 半列，理论产能约 185 / 96 / 49 条/h。
- **运行**：实时产能、良率、30×24 条带 Map 实时上色、良率趋势、事件日志。
- **物料**：上料 → 读码 → 转载 → 测试 → 分选 → 料盒的流转状态与料盒余量、Lot 进度。
- **测试**：当前扎针覆盖范围与通道占用、Kelvin 测量链路、每单元 VF / IGSS / VS1S2 实时值与 Bin、VS1S2 直方图。
- **维护**：维护模式（停机、针头退位、防护门开）、7 项保养寿命计数、针尖清洁、示例报警与复位、每班点检表。

测量数据与寿命计数均为演示用随机模拟；测试规格为示例，以美维 E-test Instruction 为准。
