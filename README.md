# 双面同时扎针测试机 ECP-DS · 3D 现场演示

GME（广州美维）30×24 双 MOSFET 嵌埋芯片基板条带的双面同时扎针自动测试机交互演示，测试源 Advantest EVA100，接触方案为**上下两张针卡（probe card）**。

单文件 `index.html`，浏览器直接打开即可（Three.js 从 jsDelivr CDN 加载，需要外网）。在线：https://ppdesea.github.io/gme-dual-probe-tester-demo/

## 方案要点

- **针卡而不是针座**：上针卡细针接触 Top 0.12×0.15 mm 焊盘（Sense + Gate），下针卡 Pogo 接触 Bottom 0.35 mm 焊盘（Force）；EVA100 测试头直接对接针卡，无长电缆。针卡是标准 PCB + 针，成本远低于全板专用针座治具，换新品只换针卡。
- **单载具直线结构，不用转台**：载具在换片位换片，长行程 X 轴送到针卡下方，对位后 XYθ Step & Repeat；大板不转台，结构简单成本低。上下针卡单元共用 C 型框架，一次对位两面同轴。
- **节拍**：换片 4 s + 进出 2 s + 对位 2 s + N × 1.2 s。512 / 256 / 128 ch 分别每次扎 2 列 / 1 列 / 半列（15 / 30 / 60 次），理论约 138 / 82 / 45 条/h；下料取放与下一条测试并行。
- **形态对标 Nidec STAR REC M6ⅡUW**：封闭机壳、L/UL 一体型料盒舱、主操作屏 + 灯带 + 急停、双开防护门、三色灯、AGV 对接预留。页面「对标」页有逐项对照：M6 做 HDI/PCB 线路 O/S 电测，本机测嵌埋 MOSFET 器件参数。

## 演示内容

- **3D 模型**：机壳（可透视）、料盒舱与上/下料取放机构、2D 读码器、XYθ 载具台与格栅真空载具 + 张力夹、对位相机、C 型框架、上下针卡单元（测试头 / 卡座 / 针卡 / 针块 / 上压板）、后部 EVA100 机柜（512ch 两台）、HMI、防护门、AGV。悬停显示部件功能，7 个视角预设，剖视·分层展开。
- **运行**：实时产能、良率、工位状态、30×24 条带 Map 实时上色（3D 条带同步）、良率趋势、事件日志。
- **物料**：上料盒 → 取放·读码 → 换片位 → 对位 → 扎针 → 下料分选 → 料盒；料盒余量、补料、Lot 进度、AGV 对接演示。
- **测试**：当前扎针覆盖范围与通道占用、针卡测量链路、每单元 VF / IGSS / VS1S2 实时值与 Bin、VS1S2 直方图。
- **维护**：维护模式（停机、针卡退位、防护门开）、针卡更换动画、针尖清洁、7 项保养寿命计数、示例报警与复位、每班点检表。

测量数据与寿命计数均为演示用随机模拟；测试规格为示例，以美维 E-test Instruction 为准。M6 数据取自 Nidec 公开产品页与 JPCA 资料。
